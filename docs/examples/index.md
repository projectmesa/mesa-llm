# Mesa-LLM Examples

This directory contains a set of core agent-based model examples that use Mesa-LLM. These examples demonstrate how large language models can be integrated as agent reasoning engines within the Mesa framework, enabling sophisticated, communication-driven behaviors.

## Overview

The examples are selected to demonstrate both foundational and advanced features of language model-powered agents in simulation. Use these as templates for your own generative agent-based models.

---

## [Epstein Civil Violence with LLMs](./epstein_civil_violence/Readme.md)


Adaptation of Joshua Epstein's classic civil violence model ([PNAS link](https://www.pnas.org/doi/10.1073/pnas.092080199)), extended with LLM-powered agents.  
Agents use prompts to assess risks, motivations, and allegiance, with emergent behaviors influenced by their synthetic "thoughts" and communications.

- **Purpose:** Explore collective protest, authority response, and narrative-driven social dynamics.


---

## [Negotiation Model with LLM Agents](./negotiation/Readme.md)

A demonstration of language-driven negotiation between multiple agents, each powered by an LLM.  
Agents communicate offers, counteroffers, and adapt strategies through dialog, allowing emergent negotiation and compromise dynamics.

- **Purpose:** Study multi-agent dialog, decision-making, and emergent social protocols in negotiation scenarios.
